# Сайт агента з нерухомості — макет за Real Estate Website Playbook

Статичний сайт (HTML + CSS + JS, без збірки, залежностей і зовнішніх запитів), побудований за структурою
плейбука «Real Estate Website Playbook» (polidori.dev), українською мовою.
Типографіка — системні шрифти Apple (SF), веб-шрифти не підключаються.

## Запуск

```bash
python3 -m http.server 5173
```
Далі відкрити <http://localhost:5173>.

## Структура

```
index.html            головна: hero → до/після → об'єкти → scroll scrub → відгуки → райони → контакти
neighborhoods.html    путівник районами + scroll scrub нової забудови
getdesign.md          дизайн-напрямок (типографіка, палітра, відступи, кнопки, рух)
css/style.css         усі стилі, токени у :root
js/main.js            навігація, поява секцій, слоти відео, scroll scrub, карусель, форма
assets/video/         слоти для відео + README з іменами файлів і командою ffmpeg
assets/img/           слоти для фото + README
robots.txt            заборона індексації (NDA)
```

## Що замінити перед релізом

1. **Відео** — покласти файли в `assets/video/` (імена в `assets/video/README.md`). Поки файлів немає, на їх місці показується заглушка з назвою файлу. Тримайте файли до ~8 МБ: через відсутність Range-запитів на Cloudflare відео вантажиться цілком у `blob:` (деталі в `assets/video/README.md`).
2. **Фото** — `assets/img/` (імена в `assets/img/README.md`).
3. **Контент-плейсхолдери:**
   - ім'я агента «Марта Коваль» — у `<title>`, навігації, hero, футері обох сторінок;
   - телефон `+380 (00) 000-00-00`, email `hello@example.com`, адреса офісу — секція контактів;
   - об'єкти, ціни, відгуки — вигадані;
   - кнопка бронювання: замінити `data-calendly` на реальне посилання Calendly (`js/main.js`, пункт 8);
   - форма: підключити обробник (Formspree / Telegram-бот / власний бекенд) у `js/main.js`, пункт 7.
4. **robots.txt і `<meta name="robots" content="noindex,nofollow">`** — прибрати після погодження релізу.
