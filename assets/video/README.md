жодних правок у коді не потрібно.

| Файл | Де використовується | Промпт із плейбука (Higgsfield) |
|---|---|---|
| `hero-aerial.mp4` ✅ на місці | Hero головної — **scroll scrub, 250vh** | Аерозйомка навколо будинку, 8 сек, золота година, орбіта з фронт-лівого боку, ~7,5 м над землею |
| `twilight-pool.mp4` ✅ на місці | Scroll scrub після лістингів (250vh) | Екстер'єр у сині сутінки, наїзд камери від дальнього краю басейну до будинку, 8 сек |
| `aerial-neighborhood.mp4` | Hero сторінки районів, автоплей у циклі | Дрон над кварталом, повільне зниження з обертанням, 9 сек |

Кожен промпт має завершуватися: **"The video must be a single continuous shot, no cuts."**

## Важливо: Cloudflare Workers і Range-запити

Workers Assets **не підтримує часткові запити**: на `Range: bytes=…` віддає `200`
і файл цілком, без `206` і `Accept-Ranges`. Safari без `206` не програє `<video>`,
а scroll scrub без діапазонів не може перемотуватись.

Тому сайт вантажить відео одним `fetch()` і підставляє через `blob:` URL
(`js/main.js`, пункт 3). Наслідок: файл має бути **невеликим** — до ~8 МБ,
інакше перший показ секції довго чекає. Обидва поточні відео пережаті
з 18 МБ до 7,1 і 5,7 МБ у 1920×1080.

## Технічні вимоги до scroll-scrub файлів

Плавність скрубу залежить не від ваги файлу, а від **щільності ключових кадрів**.
Перекодуйте фінальні відео так, щоб кожен кадр був ключовим:

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 22 -g 1 -keyint_min 1 -sc_threshold 0 -an -movflags +faststart twilight-pool.mp4
```

- `-g 1` — кожен кадр ключовий (браузер може миттєво стрибнути на будь-яку секунду);
- `-an` — звук не потрібен, автоплей без звуку;
- `+faststart` — moov-атом на початку файлу, відео стартує до повного завантаження;
- цільова роздільність 1920×1080, бажано до 12–15 МБ на файл.

Hero теж працює у режимі scroll scrub, тому й для нього потрібні щільні ключові кадри (`-g 1`). Якщо ffmpeg недоступний, відео все одно скрабиться, але можливі мікро-ривки на швидкому скролі:

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 24 -preset slow -vf scale=1920:-2 -an -movflags +faststart hero-aerial.mp4
```

Постер для hero (перший кадр): `assets/img/hero-poster.jpg`.
